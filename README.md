# Dhana Data Workbench

A Vite + React + TypeScript app for uploading, profiling, cleaning, and exporting tabular datasets entirely in the browser.

## Run it

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```bash
npm run build
```

## Preview the production build

```bash
npm run preview
```

## Notes

- The app lives in the `dhana/` folder.
- Uploaded files are processed locally in the browser.
- Shared UI tokens now live in `src/components/ui/tokens.ts`.
